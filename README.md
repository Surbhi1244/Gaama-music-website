# 🎵 Gaama – Music Website

Gaama is a music website hero page built using only **HTML** and **CSS**.
It features a clean, modern landing section designed to give visitors
a great first impression of a music streaming experience.

## ✨ Features
- Eye-catching hero section
- Clean and modern UI design
- Fully styled with pure CSS (no frameworks, no JavaScript)
- Lightweight and fast loading

## 🛠️ Tech Stack
- HTML5
- CSS3

## 🚀 How to Run
1. Repository clone karo:
   `git clone https://github.com/username/gaama.git`
2. Folder kholo aur `index.html` ko browser me open karo.
